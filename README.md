# Customer Segmentation
# About the Project
This project focuses on grouping customers based on their shopping behavior using Machine Learning. Instead of predicting values, it identifies customers with similar characteristics so businesses can better understand their customers and create targeted marketing strategies.
I used the K-Means Clustering algorithm to divide customers into different groups based on their annual income and spending score.


# Tools and Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


# Project Steps
- Loaded the customer dataset
- Explored the data and checked for missing values
- Visualized customer information
- Selected important features for clustering
- Used the Elbow Method to find the optimal number of clusters
- Applied the K-Means algorithm
- Visualized the customer segments


# Results
The K-Means model successfully grouped customers into different clusters based on their spending habits and annual income. These clusters can help businesses understand different types of customers and improve marketing strategies.
